## 動詞與語法

| English              | 臺灣正確用語               | 避免使用（中國用語）  |
| -------------------- | -------------------------- | --------------------- |
| perform              | 直接用動詞（如「執行」）   | 進行一個…的動作       |
| based on             | 根據 / 以…為基礎           | 基於                  |
| through / via        | 透過                       | 通過                  |
| target / for         | 針對（同，但臺灣較少濫用） | 針對（濫用）          |
| implement / achieve  | 實作（技術）/ 達成（目標） | 實現                  |
| get / obtain         | 取得                       | 獲取                  |
| delete               | 刪除（不加「掉」）         | 刪除掉                |
| log in               | 登入                       | 登錄                  |
| log out              | 登出                       | 註銷                  |
| download and install | 下載並安裝                 | 下載安裝              |
| run / execute        | 執行                       | 運行                  |

## 冗贅句式

| 避免使用（中國用語）   | 臺灣正確用語          |
| ---------------------- | --------------------- |
| 的話（濫用）           | 如果…的話（少用）/ 若 |
| 非常地                 | 非常（不加「地」）    |
| 進行刪除               | 刪除（直接用動詞）    |
| 做一個…的操作          | 直接描述動作          |
| 進行一個配置的動作     | 設定                  |

## 標點符號

| Wrong usage        | Correct usage  | 說明               |
| ------------------ | -------------- | ------------------ |
| , (半形逗號)       | ，（全形）     | 中文句子用全形逗號 |
| . (半形句號)       | 。（全形）     | 中文句子用全形句號 |
| : (半形冒號)       | ：（全形）     | 中文語境用全形冒號 |
| ; (半形分號)       | ；（全形）     | 中文語境用全形分號 |
| ! (半形驚嘆號)     | ！（全形）     | 中文語境用全形     |
| ? (半形問號)       | ？（全形）     | 中文語境用全形     |
| "" (直引號)        | 「」（單引號） | 臺灣用「」引用     |
| '' (直引號)        | 『』（雙引號） | 引號中的引號用『』 |

**例外：** 程式碼區塊、指令、檔案路徑中使用半形標點。
